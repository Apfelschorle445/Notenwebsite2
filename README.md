# GradeFlow

Kostenlose, responsive Noten- und Schulverwaltung als Next.js-/Supabase-Starter.

## Einrichtung

1. `npm install`
2. Supabase-Projekt erstellen und `supabase/schema.sql` im SQL Editor ausführen.
3. `.env.example` nach `.env.local` kopieren und Supabase-URL sowie anon key eintragen.
4. `npm run dev`
5. `http://localhost:3000` öffnen.

## Build

```bash
npm run build
```
